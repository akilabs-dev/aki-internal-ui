# Akilabs UI Library

Internal **UI reference library** for Akilabs: approved components, brand rules, and copy-paste code for HTML and Vue projects.

## What it provides

| Mode | Purpose |
|------|---------|
| **Live preview** | Interactive Vue render of each component |
| **Screenshot** | Static PNG reference for docs, handoff, and Slack (when added under `public/screenshots/`) |
| **Code** | HTML, Vue (SFC), CSS, and usage snippets |

## Development

```bash
npm install
npm run dev
```
