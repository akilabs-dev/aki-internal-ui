# Reference screenshots

Static PNGs for the **Screenshot** view in the Akilabs UI Library (docs, Figma handoff, Slack, etc.).

## Paths

| Entry type | File path |
|------------|-----------|
| Single component (`id: contact-form`) | `public/screenshots/contact-form/preview.png` |
| Variant (`card` → `card1`) | `public/screenshots/card/card1.png` |

Override the default path on an entry with `screenshot: '/screenshots/custom.png'`.

## How to capture

**Quick (downloads to your computer):** **Preview** → **Live** → **Save screenshot** → **+** → resize the frame → PNG saves automatically ~1s after you release the mouse. **Enter** saves without resizing; **Esc** cancels.

**For the reference library (optional):** save that PNG into the paths below, then reload — the **Screenshot** view toggle appears.

1. Open the component → **Preview** → **Live** (use **Full screen** for tall layouts).
2. Click **Save screenshot**, or export manually.
3. To publish in the repo: copy the file to the path above.

Recommended width: **1200px** (or 2× for retina). Use a neutral background matching the preview frame (`#f1f5f9` / slate-100) when possible.
